# B1 Polish Trainer

PWA-тренажер для украинского/русскоязычного пользователя, который уже понимает и использует польский в жизни или на работе, но хочет быстро подготовиться к официальному экзамену B1.

## Миссия

- Давать короткую ежедневную практику по реальным B1-ситуациям.
- Тренировать перевод RU -> PL, который пригодится в письме, говорении и типовых диалогах.
- Сохранять локальный прогресс без сервера.
- Работать как легкий PWA с офлайн-режимом.
- Давать измеримый срез готовности через мини-мок по пяти зонам.

## Целевой пользователь

- Украинский/русскоязычный взрослый ученик.
- Уже живет или работает в польской среде.
- Не начинает с нуля.
- Нуждается в быстром B1 exam sprint: письмо, говорение, грамматическая точность, чтение и аудирование.

## Методика

В основе продукта лежит интенсивная 8-недельная модель перехода `A2 -> B1` для дисциплинированного ученика.

- `20-26` часов в неделю.
- `5-6` учебных дней в неделю.
- Ежедневный `SRS`.
- `3-4` устные лаборатории в неделю.
- `2` цикла письма в неделю.
- `2` блока интенсивного аудирования в неделю.
- `1` полный B1-style мок каждые две недели.

Ключевой метрикой успеха считается не просто тестовый балл, а прохождение B1-style мока по всем пяти экзаменационным зонам и улучшение продуктивных навыков (говорение и письмо).

В `v0.3` добавлен только планировочный слой методики: структура недель, фокус, целевые активности и переключение недели в интерфейсе. Полный движок 8-недельного курса (автоматическая оркестрация задач, трекинг выполнения недели, расширенная аналитика) пока не реализован.

## 12-дневный супер-интенсив B1

Добавлен отдельный короткий экзаменационный режим для пользователя, который уже относительно хорошо понимает польский и общается с поляками в повседневных и рабочих ситуациях, но хочет быстро подготовиться именно к экзамену B1.

- Это не курс с нуля.
- Ежедневная нагрузка: `3-5` часов.
- Фокус: экзаменационный формат, письмо, говорение, грамматическая коррекция и регулярные мини-мок задания.
- Рабочий/строительный контекст используется как мост к экзаменационному польскому, а не как единственная тема обучения.

Режим включает 12 последовательных дней: диагностика, шаблоны, критичная грамматика (падежи, прошедшее время, аспект), циклы письма, интенсивное аудирование, устную лабораторию, цикл коррекции и финальный мок со стратегией экзамена.

Для каждого дня есть локальный чеклист задач с примерной длительностью, типом работы, процентом выполнения и короткой заметкой дня. Эти данные хранятся только в браузере через `localStorage`: без сервера, аккаунта и синхронизации между устройствами.

Сводка 12-дневного режима также считается локально из браузерных данных чеклиста: начатые дни, закрытые дни, общий процент, выполненные задачи и типы задач, которые чаще всего остаются незавершенными.

## Грамматические микродриллы B1

Добавлен первый практический слой грамматики для экзаменационной точности. В режиме `Грамматика` есть 50 коротких заданий:

- прошедшее время и согласование;
- падежи в B1-контексте;
- вид глагола;
- предлоги и падеж;
- согласование прилагательных и существительных.

Каждое задание содержит правильный ответ, объяснение на русском, типичную ошибку и польский пример. Прогресс и ошибки считаются только локально в браузере.

## Письменная практика B1

Добавлен режим `Письмо` для самых рискованных письменных форматов B1:

- e-mail;
- приглашение;
- объявление;
- жалоба;
- просьба;
- мнение / короткая аргументация.

В каждом задании есть обязательные элементы, полезные польские фразы, структура ответа, образец, типичные ошибки и чеклист самопроверки. Черновики сохраняются локально в браузере; автоматической AI-проверки и сервера пока нет.

## Говорение B1

Добавлен режим `Говорение` с 30 заданиями для экзаменационного формата:

- описание картинки;
- рассказ о прошлом;
- планы на будущее;
- мнение и аргументация;
- диалог;
- сравнение вариантов;
- рабочая ситуация, переведенная в нейтральный экзаменационный польский.

Каждое задание содержит ситуацию, польский prompt, трехшаговый план ответа, полезные фразы, критерии самопроверки и типичные ошибки. Есть простой таймер на 30 секунд подготовки и 90 секунд ответа. Запись голоса пока не реализована.

## Чтение B1

Добавлен режим `Чтение` с короткими текстами уровня B1. Вопросы покрывают:

- одиночный выбор;
- true/false;
- поиск детали;
- главную мысль текста.

После проверки показываются правильные ответы и объяснения на русском. Лучший результат по каждому тексту сохраняется локально в браузере.

## Аудирование и shadowing

Добавлен легкий режим `Аудирование` без внешних сервисов и backend. Приложение использует браузерный `SpeechSynthesis`, если он доступен:

- прослушивание польского текста;
- медленное повторное прослушивание;
- скрытие/показ текста;
- вопросы на понимание;
- shadowing-инструкция и полезная лексика.

Ограничение: это синтетическая озвучка браузера, а не настоящие экзаменационные аудиозаписи. Если браузер не поддерживает озвучивание, приложение показывает сообщение и предлагает читать текст вслух самостоятельно.

## Пробный мини-экзамен B1

Добавлен режим `Пробный экзамен` для первого измеримого среза готовности. Мини-мок включает 5 зон:

- чтение: 1 текст и 5 вопросов;
- лексика/грамматика: 15 коротких заданий;
- письмо: 1 prompt и чеклист самопроверки;
- говорение: 3 prompt-а и чеклист самопроверки;
- аудирование/shadowing: 1 синтетически озвучиваемый текст и 4 вопроса.

Объективные зоны считаются автоматически. Письмо и говорение оцениваются через честную самопроверку по критериям. Приложение показывает общий процент готовности, разбивку по зонам, слабые зоны и рекомендуемые следующие действия.

## Деплой на GitHub Pages

- Push в `main` запускает workflow `.github/workflows/deploy-pages.yml`.
- В репозитории должен быть включен GitHub Pages с источником `GitHub Actions`.
- Локальная разработка остается на `npm run dev`; production build использует базу `/b1/`.

## Приватность

- Аккаунт не нужен.
- Backend отсутствует.
- Прогресс хранится в `localStorage` текущего браузера.
- Данные не синхронизируются между устройствами.
- Пользователь может удалить прогресс через очистку данных сайта в браузере.

## Ограничения текущей версии

- Нет проверки письма и говорения искусственным интеллектом.
- Нет настоящих аудиозаписей дикторов; аудирование использует browser SpeechSynthesis.
- Мини-мок короткий и не заменяет официальный пробный экзамен.
- Контент покрывает первый release candidate, а не полный языковой курс.
