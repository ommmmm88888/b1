# B1 Polish Trainer

Минимальный, но рабочий тренажер для русскоязычного пользователя, который готовится к польскому экзамену B1.

## Миссия

- Давать короткую ежедневную практику по реальным B1-ситуациям.
- Тренировать перевод RU -> PL, который пригодится в письме, говорении и типовых диалогах.
- Сохранять локальный прогресс без сервера.
- Работать как легкий PWA с офлайн-режимом.
- Позже расшириться до чтения, аудирования, грамматики, письма и mock exams.

- React + TypeScript + Vite.
- Русский интерфейс.

- Seed-словарь из практических B1-фраз и моделей.

## Методика

В основе продукта лежит интенсивная 8-недельная модель перехода `A2 -> B1` для дисциплинированного ученика.

- `20-26` часов в неделю.
- `5-6` учебных дней в неделю.
- Ежедневный `SRS`.
- `3-4` speaking labs в неделю.
- `2` writing cycles в неделю.
- `2` listening-heavy блока в неделю.
- `1` полный B1-style mock каждые две недели.

Ключевой метрикой успеха считается не просто тестовый балл, а прохождение B1-style mock по всем пяти экзаменационным зонам и улучшение продуктивных навыков (говорение и письмо).

В `v0.3` добавлен только планировочный слой методики: структура недель, фокус, целевые активности и переключение недели в интерфейсе. Полный движок 8-недельного курса (автоматическая оркестрация задач, трекинг выполнения недели, расширенная аналитика) пока не реализован.

## 12-дневный супер-интенсив B1

Добавлен отдельный режим sprint/rescue для пользователя, который уже относительно хорошо понимает польский и общается с поляками в повседневных и рабочих ситуациях, но хочет быстро подготовиться именно к экзамену B1.

- Это не курс с нуля.
- Ежедневная нагрузка: `3-5` часов.
- Фокус: экзаменационный формат, письмо, говорение, grammar rescue и регулярные mini-mock задачи.
- Рабочий/строительный контекст используется как мост к экзаменационному польскому, а не как единственная тема обучения.

Режим включает 12 последовательных дней: диагностика, шаблоны, критичная грамматика (падежи, прошедшее время, аспект), writing cycles, listening-heavy, speaking lab, correction loop и финальный mock со стратегией экзамена.

## Деплой на GitHub Pages

- Push в `main` запускает workflow `.github/workflows/deploy-pages.yml`.
- В репозитории должен быть включен GitHub Pages с источником `GitHub Actions`.
- Локальная разработка остается на `npm run dev`; production build использует базу `/b1/`.
