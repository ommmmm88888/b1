# Changelog

## v0.1.0 - 2026-05-01

First public release candidate for B1 Polish Trainer.

### Added

- 12-day intensive B1 exam-prep plan with local checklist, daily note and progress summary.
- RU -> PL trainer with local progress and retry-after-error flow.
- Grammar micro-drills with Russian explanations, common mistakes and answer feedback.
- Reading, listening, writing and speaking practice modes.
- MiniMock across reading, grammar, writing, speaking and listening zones.
- PWA manifest, service worker, offline fallback and GitHub Pages workflow.

### Improved

- Compact desktop/mobile UI across all main screens.
- Mobile navigation sizing and sticky behavior.
- Feedback highlighting for wrong/correct answers.
- Answer diff and retry UX after errors.
- MiniMock active-exam sticky controls.

### Known Limitations

- Writing and speaking use self-check, not AI evaluation.
- Listening uses browser SpeechSynthesis, not recorded exam audio.
- MiniMock is short and does not replace a full official exam simulation.
