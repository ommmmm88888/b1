# Content Scope

## Что есть сейчас в v0.1.0

- RUPL словарный тренажер с нормализацией ответа.
- 12-дневный супер-интенсив B1.
- Чеклист и заметка дня для 12-дневного режима.
- Сводка прогресса 12-дневного режима.
- 50 грамматических микродриллов B1.
- 12 письменных заданий с шаблонами и самопроверкой.
- 30 заданий на говорение с планом ответа и таймером.
- 6 текстов на чтение с 24 вопросами.
- 10 заданий на аудирование/shadowing через SpeechSynthesis.
- Мини-мок по 5 зонам.
- Compact UI для desktop/mobile.
- PWA/offline support и GitHub Pages workflow.
- Vitest release gate для ключевой логики.

## Что не покрыто

- Полный официальный формат экзамена.
- Настоящие аудиозаписи дикторов.
- Автоматическая проверка письменного текста.
- Автоматическая оценка произношения или записи голоса.
- Синхронизация прогресса между устройствами.
- Backend, аккаунты, облачные ресурсы.

## Известные ограничения

- Письмо и говорение оцениваются через самопроверку.
- SpeechSynthesis зависит от браузера и доступных голосов.
- Контент достаточен для первого публичного релиза, но требует расширения перед полноценным v1.
- LocalStorage может быть очищен браузером или пользователем.
