# B1 Polish Trainer v0.1.0 RC

## Product Scope

B1 Polish Trainer v0.1.0 RC is a local-first PWA trainer for a Russian-speaking learner who already understands Polish reasonably well and needs fast preparation for the official B1 exam.

The release focuses on exam readiness, not a full language-school curriculum.

## Included Modules

- RUPL vocabulary trainer with local progress.
- 12-day B1 intensive sprint.
- 12-day checklist, daily note and full sprint summary.
- B1 grammar micro-drills.
- Writing templates and local drafts.
- Speaking prompts with answer plans and timer.
- Reading comprehension practice.
- Listening/shadowing via browser SpeechSynthesis.
- Mini mock exam across 5 zones.
- Compact desktop/mobile UI.
- Release verification tests with Vitest.
- PWA/offline and GitHub Pages workflow.

## Proof Commands

```powershell
npm run verify
```

```powershell
npm run lint

npm run build
```

## Known Limitations

- No backend.
- No account or cloud sync.
- Writing and speaking use self-check, not AI evaluation.
- Listening uses browser SpeechSynthesis, not real recorded exam audio.
- Mini mock exam is intentionally short and does not replace a full official mock.

## Manual Smoke Checklist

- Open the app locally or from GitHub Pages `/b1/`.
- Switch through all top-level modes.
- Complete one vocabulary card.
- Check and uncheck a 12-day intensive task.
- Confirm the 12-day summary changes.
- Complete one grammar micro-drill.
- Save and reload a writing draft.
- Mark one speaking prompt complete.
- Complete one reading text.
- Run one listening task, including fallback if SpeechSynthesis is unavailable.
- Finish the mini mock exam and confirm the latest result is saved.
- Reload and confirm localStorage progress persists.
- Test first-load online, then reload offline after service worker installation.

## Not Yet Included

- Full official-length mock exam.
- Human-quality audio recordings.
- AI writing feedback.
- Speech recording and pronunciation feedback.
- Cross-device sync.
- Backend-managed content.
